# Использование ИИ

## ЛР 1

- Инструмент: ИИ-агент в Cursor.
- Что сгенерировано агентом: тесты, синтетические данные в `data/`, скрипт замера, README и отчет.
- Решения, принятые студентом: траектория Backend, архитектура, основной уровень, Python, инструменты проверки, схема данных.
- Как проверялось: `ruff`, `mypy --strict`, `pytest`, установка wheel в чистое окружение, ручной
  запуск CLI на файлах из `data/`.
- Реальные работы студентов, токены и секреты агенту не передавались.

## ЛР 2

- Инструмент: ИИ-агент в Cursor.
- Что сгенерировано агентом: тесты, синтетический корпус, скрипты эксперимента, README и отчёты.
- Решения, принятые студентом: токеновый baseline, модель корпуса, сервис сравнения, индекс, кеш,

  чистое окружение.
- Реальные работы студентов, токены и секреты агенту не передавались. Все сдачи и нагрузочные записи
  синтетические.
